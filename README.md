# Gemini Live to GitHub Pages: Automated Web Development Workflow

Static documentation site describing the pipeline Gemini Live -> Google Drive (`files.watch`) -> HTTPS webhook -> IBM Bob Harness -> GitHub repository -> GitHub Pages.

Generated by IBM Bob Harness from a Google Drive document. No dependencies or build step.

## Files
- `index.html` - page content
- `styles.css` - styles
- `.nojekyll` - disables Jekyll processing on GitHub Pages

## Local use
Open `index.html` or run `python3 -m http.server`.
